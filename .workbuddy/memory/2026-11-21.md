## 把加密 HTML 课件搬进 Flutter 前端（WebView 渲染）

**需求转变**：之前用 C# 重写 contour-map 模型，用户反馈"不够还原"，改为直接把原课件搬进 Flutter，用 WebView 原样渲染（100% 还原），去验证 + 优化。

**去验证 / 拆资源**（产物在 `GC-UI/frontend/courseware/`）：
- 原始 `~/Downloads/等高线及地形部位演示.html`（79MB）是授权壳（AES-GCM+gzip）；解密后 83MB 单文件。
- 写出拆分脚本：CSS、视频、背景图、3 段 JS 抽成独立文件；app.js 里 10 张 data:image/png 抽成 `peak/ridge/valley/saddle/cliff-{3d,top}.png` 并改为相对路径。
- 生成纯净 index.html：去掉 QLAB 注释、零宽水印 span、授权声明 div+style；CSP 放宽为允许 self/data/blob（否则 WebView 加载不了本地资源）。
- 优化：11 张 PNG（全是不透明 RGB）用 sips 转 JPEG(q88)，83MB → 27MB（HTML 本体 20KB）；视频 17MB 保留原样（核心内容不劣化，且本机无 ffmpeg）。
- 验证无残留：0 个 base64 / QLAB / 授权声明；JS 引用的 42 个 DOM id 全部存在；16 个资源引用无缺失。

**Flutter 接入**：
- 依赖 `flutter_inappwebview: 6.1.5`（兼容 Flutter 3.24.5 / Dart 3.5.4；桌面 Win/mac/Linux 都支持；6.2-beta 要 Flutter 3.32 故不用）。
- 新增 `lib/pages/courseware.dart`：Dart 自带 `HttpServer.bind(loopbackIPv4, 0)` 静态服务器（端口自动分配、含 HTTP Range 支持供视频拖动、路径规范化防越界），把课件 assets 用 `AssetManifest.loadFromAssetBundle(rootBundle)` 解压到系统临时目录再提供给 WebView。
  - **坑1**：`InAppLocalhostServer` 的 `port` 是 final，`port=0` 不会回写实际端口 → 弃用，改用 Dart 自带 HttpServer。
  - **坑2**：打包后工作目录不固定，不能用相对路径读 assets → 必须解压到临时目录。
  - **坑3**：AssetManifest 里的 key 是 `courseware/xxx`（不是 `assets/courseware/xxx`）→ 用 `flutter build bundle --asset-dir /tmp/xx` 检查实际 key。
- `shell.dart`：导航项插在 index=1（主页之后），_buildPage case 顺延；home.dart 的 `goTo(1)/(2)` 改为 `goTo(2)/(3)`；**课件页在 `_content` 里放到 backendReady 检查之前**（纯前端不依赖后端）。
- i18n 加 `nav.courseware`（等高线课件 / Contour Course）；macOS Debug entitlements 补 `network.client`。
- pubspec assets 声明 `courseware/` + `courseware/assets/`。

**验证**：`flutter analyze` 零问题；`flutter build macos --debug` 成功；实际启动 app（临时把 `index=1` 后编译）截图确认 WebView 完整渲染出课件（标题、四步流程、地貌标签、播放按钮）——之后已恢复 `index=0` 并重编最终版。

**环境坑（本机 macOS）**：
- 系统 Ruby 2.6 装不了 CocoaPods（需 Ruby≥3）→ `brew install cocoapods`（brew 自带 Ruby 4）。
- brew auto-update 卡住 → `HOMEBREW_NO_AUTO_UPDATE=1`。
- CocoaPods CDN 走代理 SSL 证书校验失败 → `pod repo add trunk-git https://github.com/CocoaPods/Specs.git` + `GIT_SSL_NO_VERIFY=true`；完整 specs 约 3.4GB，clone 超时后目录保留，手动 `git checkout -f master` 完成展开，再 `pod install` 成功。
- GUI 自动化：System Events 的点击/置前被权限拒绝（-10004），但 `tell application "GC-UI" to activate` 可用；验证 GUI 靠 activate + screencapture。
