## Earth Model Studio（新建项目）
- 用户要求：C#/.NET8(可切10)，多目录结构（曾要求 gradle 命名，后明确改为标准 .NET 命名，勿再用 gradle 字样）
- 结构：src/main/dotnet + src/test/dotnet + src/main/resources + model/ + examples/ + dist/ + Directory.Build.props + build.sh/build.ps1
- 三平台一次性编译：`./build.sh publish` → dist/{mac-arm64(.app),win-x64,win-arm64}，自包含单文件 + 内置 model/ + examples/
- 技术栈：Avalonia 11.3.9 + CommunityToolkit.Mvvm 8.2.2（本地 NuGet 已缓存）；纯 CPU 球面像素渲染（SphereRaster + CelestialView）
- 模型格式：model/<id>/<id>.json + <id>.model/scene.json + land.json；模型源=git 仓库根的 model/ 目录（支持 github/gitlab/gitee zip 归档、git clone、本地目录）
- 内置模型：earth-rotation（自转）、earth-revolution（公转），land.json 手绘大陆轮廓已校验
- 校验：src/test/dotnet 用 Avalonia.Headless 渲染截图到 build/screenshots（页面+场景全通过，HUD 重叠已修）
- 已知小问题：RadialGradientBrush.Radius 过时警告；发布后 mac 单文件在沙箱内需 DOTNET_BUNDLE_EXTRACT_BASE_DIR 可写
